# 직원 Excel 일괄등록

경로: `/employees/import`

## 입력 열
- 사번 (필수)
- 이름 (필수)
- 이메일
- 입사일 (필수)
- 고용형태 (필수)
- 재직상태 (필수: 재직/휴직/퇴사)
- 부서
- 직급
- 직책
- 리더사번
- 리더여부
- 전화번호
- 비고

## 동작
1. 브라우저에서 Excel 첫 Sheet를 읽음
2. 필수열 및 필수값 확인
3. 최대 20행 미리보기
4. 서버에서 조직/직급/직책/리더사번 재검증
5. 오류가 하나라도 있으면 전체 등록 중단
6. 기존 사번은 자동 Skip
7. 정상 신규직원만 최대 200명 단위로 Insert
8. 최대 1회 1,000명

## 주의
부서/직급/직책은 시스템에 등록된 명칭과 동일해야 합니다.
리더사번은 Excel에서 같이 신규등록하는 사람이 아니라,
현재 employees 테이블에 이미 등록된 직원 사번을 사용합니다.
