# 평가대상 최신 직원목록 자동동기화

평가기간 상세 화면은 캐시된 직원목록이 아니라 현재 `employees` 테이블을 매번 다시 조회한다.

동기화 시점:
- 평가기간 상세 페이지 진입
- 브라우저 탭으로 다시 돌아왔을 때
- 브라우저 창이 다시 포커스됐을 때
- 화면을 열어둔 동안 10초마다
- `지금 새로고침` 버튼 클릭
- 직원 신규등록/수정/영구삭제/Excel 일괄등록 직후 서버 캐시 무효화

## 신규 직원
신규 직원은 기존 평가기간을 다시 만들 필요가 없다.
현재 평가기간에 아직 assignment가 없다면 `평가대상 자동배정`의 미배정 후보로 나타난다.
평가기간이 `active`인 경우에도 추가 등록 시 snapshot을 즉시 생성한다.

## 삭제 직원
직원 영구삭제 기능이 해당 직원의 evaluation_assignment를 함께 삭제한다.
평가기간 화면은 다음 자동동기화 시점에 삭제된 직원을 즉시 제거한다.

## 평가자 직책 명칭
- `leader` 내부코드 = 부서장
- `division_head` 내부코드 = 본부장
- 기존 `executive` 내부코드는 migration 026에서 `division_head`로 전환

평가 규칙:
- 일반 구성원: 같은 부서 부서장 1차 → 본부장 2차
- 부서장: 상위 본부의 본부장 1차 → 본부장 2차
