# AMCOMPANY Excel 기반 인사진단

## 입력 Excel
`2026년 상반기_미팅체크리스트(리더 작성).xlsx`

시트: `미팅내용`

### 기본정보
- C4: 부서
- C5: 직무레벨
- C6: 성명

### 1. 진단 요약
- C11 / D11: 성장 / 진단내용 / 근거
- C12 / D12: 신뢰
- C13 / D13: 전문성
- C14 / D14: 감각

### 2. 성장 포인트
- C19 / D19: 성과 / 세부항목 / 이유
- C20 / D20: 역량
- C21 / D21: 태도

### 3. 성장 방향
- B:C / D, 26~28행: 성장영역 / 목표·시도방안

### 4. 기타 코멘트
`4. 기타 코멘트` 제목 아래 최대 5개 행의 입력값을 합쳐서 가져옵니다.

## Workflow

### 일반 구성원
Excel 업로드
→ 부서장: 진단 요약
→ 부서장: 성장 포인트
→ 본부장: 성장 방향 제안
→ 최종 완료

### 부서장 또는 기존 리더
Excel 업로드
→ 본부장: 진단 요약
→ 본부장: 성장 포인트
→ 본부장: 성장 방향 제안
→ 최종 완료
