직원목록 실시간 반영 + 부서장/본부장 평가자 명칭 패치

변경사항
1. 직원 신규등록/삭제/Excel 등록 내용을 기존 평가기간에 최신 반영
2. 평가기간 상세는 DB 직원목록을 매번 새로 조회 (force-dynamic)
3. 탭 복귀/창 포커스/10초 주기/수동 버튼으로 자동 갱신
4. 새로 추가된 직원은 현재 선택한 부서장의 평가대상에 자동 추가·체크
5. 삭제된 직원은 평가대상 후보/선택에서 자동 제거
6. 기존 '리더' 평가자 구분 -> '부서장'
7. 기존 '임원' 평가자 구분 -> '본부장'
8. 평가자 선정은 직원의 리더 여부 boolean이 아니라 직책관리의 평가자 구분을 기준으로 함

평가 규칙
- 일반 구성원: 같은 부서 부서장 1차 -> 본부장 2차
- 부서장: 상위 본부 본부장 1차 -> 본부장 2차

[5] 실시간 반영 테스트
A. 평가기간 상세 화면을 열어둠
B. 다른 탭에서 직원 한 명 신규등록
C. 평가기간 탭으로 돌아오면 즉시 갱신됨
   또는 최대 10초 안에 자동 갱신
D. 해당 부서장을 이미 선택한 상태라면 신규 직원이 목록에 추가되고 자동 체크됨
E. 직원 영구삭제 시 해당 직원의 평가데이터/assignment 삭제 후 평가기간 화면에서도 자동 제거됨

중요
- 새 직원이 평가대상으로 조회되려면 부서가 지정되어 있어야 함.
- 일반 구성원의 1차 평가자는 동일 부서의 '부서장' 직책이어야 함.
- 본부장은 직책관리 평가자 구분을 '본부장'으로 지정해야 함.
