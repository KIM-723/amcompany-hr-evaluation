진단이 아직 없거나 일부 상태에서 직원이 빠질 수 있었음.

수정:
- 직원 개별조회 목록의 기준을 evaluation_assignments로 변경
- 선택 평가기간의 현재 평가대상 전체 직원 표시
- 진단 미등록 직원도 목록에 표시

- 진단이 있으면 상태와 AI 결과 연결

문제 2:
AI 분석 버튼 클릭 후 서버 응답이 올 때까지 화면 반응이 없었음.

수정:

- 점수·근거 생성
- 결과 저장
- 완료
- 오류 발생 시 화면에 오류 메시지 출력

1명 분석의 %는 처리단계 기반 진행 표시이며 API 응답 시 100%가 됩니다.
