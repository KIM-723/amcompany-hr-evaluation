방식으로 전환합니다.

[4] 사용순서
--------------------------------------------------

1. 평가기간 생성
2. 평가대상/부서장/본부장 배정
3. 인사진단 -> Excel 업로드
4. 평가기간 선택
5. 구성원에게 받은 Excel 여러 개 선택
6. 미리보기 확인
7. 'Excel -> 인사진단 자동 작성'
8. 인사진단 -> 진단 작성
9. 일반 구성원:
   부서장이 1. 진단요약 + 2. 성장포인트 작성/확정
   본부장이 3. 성장방향 작성 -> 최종완료
10. 부서장/기존 리더:
    본부장이 1 + 2 + 3 모두 작성 -> 최종완료
11. 인사진단 -> 진단 결과 확인

--------------------------------------------------
중요
--------------------------------------------------

Excel의 대상자는 현재 양식에 사번 칸이 없으므로
'성명 + 부서'로 직원목록과 연결합니다.

동명이인이 있는 경우 부서가 정확히 일치해야 합니다.

Excel 업로드 전에 해당 직원이 선택한 평가기간의
평가대상으로 먼저 배정되어 있어야 합니다.

기존 점수형 자기평가/1차평가/2차Review/Calibration/9-Block 데이터는
삭제하지 않습니다. 새 메뉴에서는 숨기기만 합니다.
