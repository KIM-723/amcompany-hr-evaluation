부서장 평가 조회 0명 Fallback Hotfix

현재 문제:
본부장 직원의 소속부서(예: 임원)에 departments.parent_id로 연결된
산하조직이 없으면 기존 로직은 조회 결과가 0명이 됨.

변경:
1. 본부장 소속조직에 산하조직 연결이 있으면
   -> 해당 산하 전체 조직의 부서장/리더만 조회

2. 산하조직 연결이 하나도 없으면
   -> 전체 재직 부서장/리더를 자동 조회
   -> 전원 자동체크
   -> 필요한 사람만 체크 해제 가능

3. DB 등록 검증도 같은 fallback 규칙 적용

4. 부서장평가 2차 평가자 선택사항 기능 유지
